# NextLeet

![NextLeet Banner](https://nextleet.com/banner-image.png) <!-- Replace with actual image if available -->

**NextLeet** is a comprehensive platform for **coding interview preparation**. It helps users prepare for coding interviews by providing **company-wise problems**, **code analysis tools**, and **system design notes**. Whether you are a beginner or an experienced developer, NextLeet equips you with the resources to ace your next technical interview.

---

## Features

### **1. Company-wise Problem Practice**

-   Access coding problems categorized by companies like **Google, Amazon, Microsoft**, and more.
-   Filter problems based on **difficulty** and **topic**.

### **2. Code Analysis**

-   Write, test, and optimize your code.
-   Get insights on **time complexity, space usage**, and potential improvements.
-   Compare your solutions with **official or top solutions**.

### **3. System Design Notes**

-   Comprehensive notes for system design interviews.
-   Covers **scalability, caching, load balancing**, and **database design**.
-   Real-world examples to understand concepts.

### **4. Personalized Dashboard**

-   Track progress and problem-solving statistics.
-   Bookmark favorite problems and revisit them anytime.

### **5. Dark/Light Mode**

-   Seamless theme switching for a comfortable coding experience.

---

## Tech Stack

-   **Frontend:** React, Tailwind CSS
-   **Backend:** Node.js,Appwrite, Express
-   **Database:** MongoDB
-   **Authentication:** Google OAuth
-   **Deployment:** Vercel / Netlify
-   **Other Tools:** Pre-rendering & SSR for SEO optimization
